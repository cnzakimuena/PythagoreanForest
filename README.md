# PythagoreanForest
Script implementing Pythagorean Forest ([Poličar, 2016](http://eprints.fri.uni-lj.si/3431/)) which displays learned decision tree models from Random Forest ([Ho, 1995](https://doi.org/10.1109/ICDAR.1995.598994); [Breiman, 2001](https://doi.org/10.1023%2FA%3A1010933404324)) as Pythagoras trees (Bosman, 1957; [Beck et al, 2014](https://ieeexplore.ieee.org/abstract/document/7294394/)). The Iris dataset ([Anderson, 1935](https://wiki.irises.org/pub/Hist/Info1986SIGNA37/SIGNA_37.pdf); [Anderson, 1936](https://doi.org/10.2307/2394164); [Fisher, 1936](https://doi.org/10.1111/j.1469-1809.1936.tb02137.x)) is used for demonstration. The implementation is compatible with MATLAB R2019b.

Usage:

```matlab
call_PythagoreanForest()
```
